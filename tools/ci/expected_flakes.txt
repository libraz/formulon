# Expected-flake allowlist for the native CI job.
#
# This file is a *debt registry*, not a permanent feature. Each entry names a
# test that the native CI job is allowed to fail. Drain the list as the
# underlying issues are fixed -- removing an entry is equivalent to a
# regression-gate flip for that test.
#
# Drain procedure:
#   1. Reproduce the failure locally (`ctest -R <name> --output-on-failure`).
#   2. Land the fix on a feature branch.
#   3. Delete the line from this file in the same PR. CI will then enforce
#      the test on every subsequent PR.
#
# Format: one test name per non-comment line. Inline comments after `#` are
# ignored by `tools/ci/check_test_failures.py`. Test names match what gtest
# emits (`TestSuite.TestName`) or what ctest registers (e.g.
# `formulon_ironcalc_oracle`).
#
# An entry must name a test CTest actually registers in the configuration CI
# builds, which is Debug: `check_test_failures.py` rejects a stale name, and a
# test compiled only under NDEBUG is invisible to that job.
#
# IMPORTANT: do not add new entries without a stated reason. The allowlist
# must shrink monotonically across releases.
