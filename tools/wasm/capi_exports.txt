# C ABI symbols exported by the capi WASM variant (consumed by
# packages/python via wasmtime-py).
#
# One symbol per line, no leading underscore -- FormulonWasm.cmake
# prepends one before passing to emcc's -sEXPORTED_FUNCTIONS.
#
# Lines starting with # are comments. Blank lines are ignored.
#
# The list is curated, not the full 181-symbol C ABI: only what the
# Python binding currently calls is included so the WASM stays as
# small as practical. When the Python binding grows a new entry point,
# add the corresponding symbol here and the wasmtime allocator helpers
# below will pick it up.
