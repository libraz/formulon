「準拠」の意味するもの

Formulon プロジェクトの "1-bit compatibility with Excel 365" の運用上の意味:

  • Primary oracle: 各 track に primary target を 1つ持つ (formula: mac-365-ja_JP, workbook: win-365-ja_JP)。 CI gate はこの primary に対してのみ評価される。
  • Variant oracle: 追加 target は tests/oracle/variants/<target>/ に opt-in で配置、 FORMULON_ORACLE_VARIANTS=ON で有効化。Research 用、CI gate 対象外。
  • Divergence: tests/divergence.yaml で per-target scope (applies_to:) を持って documented。 全 entry に reason + last_verified_excel_version 必須。
  • Closure: 関数毎に 6条件 (behaviors_declared / cases_cover_behaviors / golden_present / divergence_documented / not_in_pilot / behavior_drift) で評価。

つまり「Mac/Win 両準拠」の達成基準は 「primary oracle で 100% pass、それ以外は documented divergence で説明可能」。 現状はこの基準を達成している。

  2. Behavior taxonomy 整備 (ARRAYTOTEXT / GETPIVOTDATA / PHONETIC を 5件以上に拡充) ⇒ 残り 3関数の OPEN が閉じる ⇒ 522/522 closure
  3. Variant target 拡充 (mac-365 workbook、win-365 formula 等の対照採取) ⇒ cross-target drift の体系的観測

いずれも Excel 側のキャプチャ作業 / 分類作業 であり、Formulon の C++ 実装変更は不要。
